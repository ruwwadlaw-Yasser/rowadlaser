# نظام نشر مقالات المدونة — رواد الليزر

هذا النظام يسمح بإضافة مقال جديد للمدونة **بأمر واحد**، بحيث تُنشأ صفحة المقال كاملة
(بنفس تصميم الموقع + بيانات SEO)، وتُضاف بطاقته في أعلى صفحة المدونة، وتُحدَّث خريطة
الموقع `sitemap.xml` تلقائياً — بدون أي تعديل يدوي في الأكواد.

---

## 1) الملفات

| الملف | الوظيفة |
|---|---|
| `tools/new_article.py` | المولّد: يأخذ ملف وصف (spec) وينشئ المقال + البطاقة + يحدّث الخريطة |
| `tools/spec-example.json` | مثال جاهز لملف الوصف — انسخه واملأه |
| `tools/specs/` | ملفات وصف المقالات المنشورة (للرجوع إليها) |
| `tools/_top.html`, `tools/_footer.html` | قوالب الرأس/التذييل (لا تعدّلها يدوياً) |

---

## 2) إضافة مقال يدوياً (خطوتان)

**أ. جهّز ملف الوصف** — انسخ `spec-example.json` وسمّه مثلاً `tools/specs/post16.json` واملأ الحقول:

```json
{
  "slug": "post16",
  "title_ar": "عنوان المقال بالعربية",
  "title_en": "Article title in English",
  "page_title": "عنوان المقال | مدونة رواد الليزر",
  "desc_ar": "وصف مختصر للسيو (150–160 حرفاً) يحتوي كلمة البحث المستهدفة.",
  "tag_ar": "دليل", "tag_en": "Guide",
  "date": "2026-08-10", "date_ar": "10 أغسطس 2026", "date_en": "Aug 10, 2026",
  "read_ar": "4 دقائق قراءة", "read_en": "4 min read",
  "excerpt_ar": "سطر يظهر في بطاقة المدونة.",
  "excerpt_en": "One line shown on the blog card.",
  "body_html": "<p data-ar=\"...\" data-en=\"...\">...</p>\n<h2 data-ar=\"...\" data-en=\"...\">...</h2>\n..."
}
```

> **مهم:** كل فقرة/عنوان في `body_html` يفضّل أن يحمل `data-ar` (عربي) و`data-en` (إنجليزي)
> ليعمل مبدّل اللغة في الموقع. استخدم `<h2>` للعناوين و`<ul class="bullets"><li>` للقوائم.
> استخدم `slug` جديداً غير مستخدم (post16, post17, ...).

**ب. شغّل المولّد:**

```bash
cd "path/to/موقع"
python3 tools/new_article.py tools/specs/post16.json
```

ثم راجِع الناتج محلياً، وإذا أعجبك انشره:

```bash
git add -A && git commit -m "مقال جديد: عنوان المقال" && git push
```

خلال دقيقة تقريباً يظهر على الموقع المباشر، وتُحدَّث خريطة الموقع تلقائياً.

## 3) أن يكتب الذكاء الاصطناعي المقال وينشره (Claude Code)

هذا هو الهدف: تعطي كلود الموضوع فقط، وهو يتولّى الباقي. اكتب له طلباً مثل:

> «اكتب مقالاً جديداً للمدونة عن **[الموضوع]**، بتصنيف **[التصنيف]**، ثم أنشئ ملف الوصف
> في `tools/specs/`، وشغّل `tools/new_article.py`، واعرض لي معاينة قبل النشر.»

كلود سيقوم بـ:
1. كتابة محتوى المقال (عربي/إنجليزي) بصيغة `body_html`.
2. إنشاء ملف الـ spec وتشغيل المولّد.
3. عرض معاينة للمراجعة، ثم — بعد موافقتك — الرفع للموقع (`git push`).

**نصيحة:** أبقِ خطوة المراجعة قبل النشر (الموقع تجاري وحقيقي). يمكن لاحقاً جدولة
كلود لتوليد مقال دورياً (مثلاً أسبوعياً) وإبقائه كمسودّة تعتمدها بضغطة واحدة.

## 4) الأرشفة في Google (مهم)

النشر على الموقع **لا يعني** الظهور فوراً في جوجل. لضمان الأرشفة السريعة:

1. **Google Search Console** — سجّل الموقع مرة واحدة على <https://search.google.com/search-console>
   وأضِف خريطة الموقع: `https://rowadlaser.com/sitemap.xml`.
   (بعدها كل مقال جديد يُكتشف تلقائياً لأن الخريطة تتحدث ذاتياً.)
2. عند نشر مقال مهم، استخدم أداة **«فحص عنوان URL» → «طلب الفهرسة»** في Search Console
   لتسريع أرشفته.
3. جوجل يقرّر الترتيب حسب جودة المحتوى وصلته بكلمات البحث والروابط — الاستمرارية مهمة.

> ملاحظة: جوجل لا يدعم الفهرسة الفورية عبر الأدوات التلقائية؛ الطريق الموثوق هو
> Search Console + خريطة موقع محدّثة (وكلاهما جاهز الآن).
