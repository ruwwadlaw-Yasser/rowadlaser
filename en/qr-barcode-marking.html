Why a code is engraved, not stuck on

Tracking, inventory and maintenance systems all rest on one assumption: that the code exists and is readable. In reality, an adhesive label in a factory, workshop or construction site meets oils, solvents, heat, pressure washing and abrasion — and falls off or becomes unreadable within months.

A laser-marked code is part of the metal surface. It cannot be peeled, wiped or faded, and stays readable by phone or industrial scanner for the part's whole life. That is the difference between a traceability system that actually works and one that needs re-tagging every year.

Which code type to choose

  • QR code: the most common — readable by any phone with no special app, and holds a full link that opens a service record or manual.
  • Data Matrix: fits far smaller areas and stays readable even if part of it is damaged — the industrial standard for small parts.
  • Linear barcode (Code 128 / Code 39): best if your warehouse or point-of-sale system already runs on a linear scanner.
  • Not sure? Tell us the system you will scan with, and we will recommend the right type and size.

Sizes and readability

What size guarantees the code can be read?

The most common mistake is shrinking the code below what its content allows. These are the practical figures we work to.

Code typeSmallest practical sizeNote
QR with a short link8 × 8 mmEasily phone-readable — the most requested size for equipment plates.
QR with a long link15 × 15 mmA long link means smaller modules — we always recommend shortening the URL.
Data Matrix5 × 5 mmThe best option for small parts, readable even when partly damaged.
Linear barcode25 × 6 mmNeeds more length — impractical on narrow parts.
Code on a curved surface+30% over the sizeCurvature distorts reading, so we enlarge the code and place it in the flattest area.

We physically test every code with a scanner and a phone before delivery — we never ship a code we have not read ourselves.
